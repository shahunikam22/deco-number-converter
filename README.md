# Universal Number System Converter

A web-based converter for **Binary, Octal, Decimal and Hexadecimal** number systems.

**Subject:** Digital Electronics and Computer Organization (DECO) mini project

**Institute:** AISSMS Institute of Information Technology, Pune (2026-27)
**Guide:** Dr. Pragati  Mahale

## Features
- Choose the input number system (Binary, Octal, Decimal, Hex)
- Input validation for each base
- Converts to all four systems at once
- One-click Copy for each result
- Supports very large unsigned whole numbers (uses BigInt)

## Limitations
- Unsigned whole numbers only (no negatives or fractions)

## Run locally
Open `index.html` in any browser. No build step or dependencies needed.
